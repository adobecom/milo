# Elastic Carousel

Card headings and descriptions remain fully visible without hover or focus,
including when users override text spacing.

On mouse-enabled tablet and desktop layouts, text keeps its resting width and
reserves room for the footer arrow while the media expands. Cards do not shrink
their neighbors, so interaction does not change the carousel height or move the
content below it.

On phones, text uses the narrowest animated stack width throughout scrolling.
The card background and media still narrow, without changing text wrapping or
feeding height changes back into the scroll-driven animation.
