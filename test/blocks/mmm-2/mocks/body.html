How to use this report
  1. Search for your pages and adjust filters if desired
  2. Click on a page to open more details
  3. Look through the list of manifests and select an experience you would like to see. *
  4. Select any options you would like to include
  5. Click Preview

Tutorial Learn more

* Note: Keeping “None” selected does not add the manifest to your preview URL and will not force the manifest to load. But if the manifest is still attached to the page, it will load anyways. If you want to force the default experience, choose “Default” from the dropdown menu

How to use this report
  1. Choose the appropriate repo from the dropdown (you can only check one repo at time)
  2. Click this button to open the corresponding spreadsheet
    Open CC Spreadsheet
  3. Enter production URL(s) below
  4. Click the "Copy Report" button and paste that report into Jira to preserve a record of the page settings before you update
  5. Use the categorized paths to know what updates are needed in the spreadsheet. You can copy each path list if needed.
  6. Preview and publish the spreadsheet
  7. Reload this page to confirm that the page settings are updated and update MMM.
